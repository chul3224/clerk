Feature Overview
Feature 01

실시간 STT

WebSocket 기반 실시간 음성 인식. 말하는 즉시 텍스트로 출력되며, 회의 도중 메모장과 나란히 확인 가능.

Deepgram nova-2
Feature 02

3개 AI 모델 비교

Llama 3.3 70B · Llama 4 Scout · Qwen3 32B를 동시에 실행. 속도, 토큰, 품질을 탭별로 비교.

Groq API
Feature 03

Cursor 스타일 탭

모델 A·B·C·비교·마인드맵 탭을 파일처럼 열고 닫으며, 좌우 패널 크기를 자유롭게 드래그 조절.

Split Panel
Feature 04

Slack 공유

요약·결정사항·액션아이템을 인라인 편집 후 Slack 채널로 원클릭 전송. n8n 워크플로우 연동.

n8n Webhook
Feature 05

히스토리 사이드바

오늘·어제·이번 주·이전으로 그룹화된 회의록 히스토리. Codex 스타일 사이드바로 즉시 조회.

SQLite DB
Feature 06

테마 · 설정

밝음 / 어두움 / 기기 설정 3가지 테마. CSS 변수 기반으로 전체 UI가 즉시 전환.

Light · Dark · System
