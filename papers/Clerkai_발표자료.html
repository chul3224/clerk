Dify vs n8n — 역할 구분
n8n 역할

데이터 전달 파이프

회의록 처리 완료 시 Dify API로 문서를 push.
n8n 자체는 RAG를 수행하지 않고 데이터를 전달하는 역할.

Dify 역할 (적용 예정)

문서 기반 AI 답변 (RAG)

벡터 인덱싱 → 유사도 검색 → LLM이 문서 기준으로 답변.
"저번 달 결정사항이 뭐였지?"에 출처 포함 답변 가능.

실무 적용 시 가능한 것
→과거 회의 결정사항 AI 검색 (출처 명시)
→팀 내 지식베이스로 온보딩 신입 질문 자동 답변
→CS 고객사 FAQ·정책 문서 → AI 상담 보조 답변
→n8n 노드 추가만으로 Notion·Confluence 문서도 동일하게 적재 가능

Split Panel

n8n Webhook
Feature 05 · 확장 예정
